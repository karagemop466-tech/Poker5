## Decision rule and top line

This planner calls an event **confirmed strict single-entry** only if an official, event-specific source clearly limits each player to one total paid entry, with no re-entry, re-buy, additional flight, or equivalent route to another entry. A “1Day” label, one listed start, or a structure sheet's silence is not proof.

- **Confirmed strict single-entry events in the reviewed window: 0.** This is “none verified in these reviewed sources,” not proof no such event exists.

Suggestions

How to review before implementing

  1. Read each suggestion below.
  2. Decide its priority and whether it fits the goal (more verified information, better decision support).
  3. Claim a suggestion in COORDINATION.md (write your session ID + file scope, commit, push) before editing.
  4. Implement, verify against official sources, then mark it done in COORDINATION.md.

Decision-making suggestions
  • Before booking, answer every item in Open Questions.
  • Review every item on the Flagged for Review page and decide whether to accept, correct, or remove each row.
  • Compare the true all-in hotel cost (rate + resort fee + ~13.38% tax), not the advertised nightly rate.
  • Confirm entry rules (single entry vs re-entry) for each tournament you plan to enter.
  • Set a total trip bankroll first, then pick tournaments that fit (use suggested cost calculator S6 once built).

Findings

  • Best guarantee per dollar: the $600 events (Dec 6 and Dec 7, $40,000 each) at about 66.7×. The Nov 27 $600 event ($30,000) is about 50×.
  • The $200 bounty events list an $8,000 guarantee (40× ratio). The schedule says that guarantee includes the bounties.
  • Prize pool share is highest on the $600 events (85%) and the $400 event (83.75%). The $200 events are 80% to 82.5%.
  • Multi-flight events (Venetian Event 7, $75,000 guarantee) are not in the single-entry list, because one flight can be entered more than once. They are in the separate section.
  • The Venetian's poker suite requires a $300+ buy-in each night, so a $300+ single-entry event meets that condition. Events at $300 or more are: Events 2, 10, 12, 14, 16, 28 and 30.

Limits of this analysis

  • Guarantees and buy-ins are official, but actual prize pools depend on the number of entries.
  • Field sizes are not verified from official sources, so expected value and return on investment are not calculated.
  • Hotel costs, walking times and the true cost per night are not included (see Questions).
Data verified against official operator pages and PDFs on 2026-11-16. Blank fields are values that could not be confirmed from an official source. This is planning information, not a booking or travel guarantee. Confirm times, buy-ins and rates with each room before you go.

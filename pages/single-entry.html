Events that satisfy the single-entry standard

The brief asks for tournaments you cannot buy an advantage in: no double buy-in, no add-on, no rebuy, no paid path to more chips. This page is the list that survives that filter, and the sentence after each event number says exactly how far the evidence goes.

The standard, written out

Grade A — 0 rows
an official source states a one-entry, no-re-entry or freezeout limit. Nothing in this window does.
Grade B — 53 rows
the event's own official structure sheet was read in full, that sheet lists this event number, the event is one day, and no re-entry, rebuy, add-on, purchased-stack or extra-flight sentence exists on it. The “unverified” label is removed from these rows, and the caveat that silence is not a published rule stays printed on each row.
Excluded — 75 rows
re-entry / add-on / extra flights / a membership-priced first buy-in is published, or the row is a continuation row rather than a purchasable entry. They live on the advantage page.
Unread — 84 rows
the room publishes no structure sheet for the event (mostly WPT festival rows and the South Point daily list). Blank and flagged.

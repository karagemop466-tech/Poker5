Questions to resolve

Every question below is either answered from an official source, answered with a stated assumption, or open. An open question is not a reason to guess: it is a reason to leave the value blank, which is why several columns on this site are empty.

Q01When is the trip, and how many are travelling?UnresolvedBlocks the trip total and the hotel logNothing official depends on it, but every cost answer does: the rate log, the number of nights and the party size all key off these three facts.You provide the dates and the number of adults. Until then the planner uses the logged snapshot stay (Dec 2 - Dec 9, 2026) as an example only.
Q02What is the nightly budget and the minimum hotel quality?UnresolvedBlocks the hotel choiceThe brief asks for cost and quality over distance, but no official page publishes a quality score, so quality has no source yet.Pick a quality standard (for example a published star rating) and a nightly cap. Then the hotels page can rank with numbers instead of blanks.
Q03Is the 8:00 AM start a hard requirement?AnsweredResolved by the official schedules: no 8:00 AM start existsThe earliest official start found is 9:00 AM (Horseshoe, six daily events). Caesars Palace starts at 10:00 AM; the Venetian's earliest is 9:10 AM.Either accept a 9:00 AM start or add a non-tournament morning activity. No source can move a room's published start time.
Q04Which events are genuinely single-entry?AnsweredAnswered for 55 rowsEach confirmed row's own structure sheet was read, lists that event number, is a one-day event and contains no re-entry, rebuy, add-on or purchased-stack language.For the rows still unverified, the sheet is either unreadable or does not name the event; the row links both the schedule and the sheet so it can be checked.
Q05How long does a hotel-to-room walk take?UnresolvedBlocks the 30-minute rule for every off-property hotelNo casino publishes a walking time. Only on-property routes are zero minutes by definition.Measure each route once on a named map service, record the provider, the route and the date, and it can enter the walking table with that source.

Sources & method

Confirmation standard used on this site.
  1. A value is shown only when an official source states it, and the row links that source.
  2. A tournament is called confirmed single-entry only when its own event-matched structure sheet explicitly states a one-entry cap / freezeout and prohibits re-entry, rebuy and add-on. Silence is not treated as proof of a prohibition. Any unstated field stays blank and is flagged.
  3. A structure sheet's own words are quoted next to the value they support, so the quote can be checked against the PDF in one click.
  4. If two official sources disagree, both values are shown and the row is flagged. Nothing is averaged or chosen.
  5. If a value is missing, the cell is blank and appears on the Flagged page. No value is inferred, estimated, or carried over from a third-party site.
  6. Every page is rebuilt from the stored capture, and the build fails if a data row has no source link or if an internal link is broken.

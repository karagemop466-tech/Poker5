The verification rule

  • Every value on this site was read from an official source - the casino's own site or its own PDF - during this session, on 2026-11-19.
  • An event is labelled No second entry granted (S1 screen) when its own official structure sheet was read in full and no numbered rule grants a re-entry, re-buy, add-on, buy-back, subsequent or additional buy-in, or a purchased or alternate stack. No sheet in the series states a one-entry limit in words - flag F01 records that gap, so the label asserts only what the sheet shows.
  • It is labelled Multi-entry when the official text allows re-entry, an add-on, or more than one starting flight.
  • It is labelled Entry cap not stated when the official sheet is silent. Silence is never promoted to single-entry.
  • A value that no official source states is left blank and appears on the Flagged page.
  • The build fails if a table row lacks an official source link, or if an internal link is broken.

What this audit did not do

  • It did not read the entry terms of every WPT festival event individually (13 of them were read).
  • It did not retrieve any official schedule for Bellagio, MGM Grand, ARIA or Planet Hollywood; those official pages returned errors.
  • It did not capture a single dated room rate; official booking engines require JavaScript.
  • It did not measure or estimate any cross-property walking time.
  • It did not estimate a finish time for any event, because no official source publishes one. The overlap check uses the official start time and the official late-registration close time.

Limits of the automation, stated plainly

  • The monitor detects change; it does not rewrite rows. scripts/recheck_ea99006a.py re-fetches all 96 official URLs, hashes them and records what changed. It does not parse a changed schedule back into table rows, because doing that silently would risk inventing values. When a source changes, the row is flagged on the Source monitor page and a person re-reads it.
  • There is no live hotel rate lookup. Every official booking engine here is a JavaScript application, so no rate can be read from an official source without a browser. The hotels page gives you the dated booking link and a calculator; you paste the rate you see and it is stored as a dated log entry.
  • No value is ever inferred. Where an official source is silent the cell is empty and the item is on the Flagged for review page.

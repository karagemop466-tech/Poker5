Suggestions board

Every improvement, its options and its consequence, so a path can be chosen before anything is implemented. Items marked implemented in this build are live now; the rest wait for a decision and are deliberately not half-built. Tick a box to record a choice in this browser — nothing is sent anywhere.

Problem
A reader cannot tell at a glance whether an event is a freezeout, a re-entry or simply unknown.
Options
  • Keep the three-way label (confirmed / multi-entry / unverified)
  • Add a plain-English sentence per row ('You may buy in again until 4:55 PM')
  • Add a colour-coded badge and drop the text
Effect of choosing
The second option costs one more column and removes most misreads. It does not change any data.

Problem
Silence on a structure sheet is not a one-entry promise, so nothing can be confirmed as a freezeout.
Options
  • Email each room's tournament desk and publish the reply with a date
  • Photograph the printed structure sheet in the room on the day
  • Leave the rows unverified and plan around them
Effect of choosing
Only the first two can move an event from unverified to confirmed. Until then a freezeout plan is an assumption.

Problem
Room rates move daily; a single figure goes stale and the true nightly cost with it.
Options
  • Keep the dated rate log and paste a new quote each time you check
  • Add a screenshot field per log entry
  • Show only the resort fee and tax, which are stable
Effect of choosing
The log is the only option that keeps a like-for-like history. Screenshots make disputes resolvable.

Problem
No official source publishes hotel-to-poker-room walking times, so the 30-minute filter is nearly empty.
Options
  • Record the walking time you measure and store it with a date
  • Only accept on-property hotels until a walk is measured
  • Accept a third-party routing estimate and label it as an estimate
Effect of choosing
The first option makes the filter useful and stays honest. The third fills the table but is not an official value.

Problem
Schedules, structures and fees change without notice.
Options
  • GitHub Actions cron at 13:00 UTC (6 AM Las Vegas) every day
  • Twice daily (06:00 and 18:00 Las Vegas)
  • Weekly
Effect of choosing
A morning run matches the brief's 'pull the schedule each morning'. Twice daily catches intraday changes at double the Actions minutes.

Problem
Earlier sessions each left a dashboard in its own folder; the same question has several different answers.
Options
  • Keep this root site as the single answer and demote the rest to an archive index
  • Keep every dashboard and add a comparison page
  • Delete the older dashboards
Effect of choosing
The first option gives one answer per question and keeps earlier work reachable. Deleting loses source history.

Problem
A multi-entry event can cost two, three or more buy-ins; a plan that assumes one entry understates the cost badly.
Options
  • Show both totals side by side on the planner
  • Show only the single-entry total
  • Show a range with no assumptions stated
Effect of choosing
Side-by-side totals make the downside visible before you commit money.

Problem
Every value here is a snapshot from an official page on 2026-11-17.
Options
  • Re-run the source check and read the change log before booking
  • Call the room and the hotel to confirm
  • Book a refundable rate only
Effect of choosing
Refundable rates are the cheapest insurance; Caesars and Horseshoe advertise free 48-hour cancellation and Resorts World requires 48 hours' notice for a deposit refund.

How to read the board

No suggestion changes a source value. Anything that would — for example importing third-party walking times or review scores — is written as a question on the Questions page instead, because it would break the official-source rule the site exists to keep.

Poker5 is an independent planning tool written by agent sessions from official sources. It is not affiliated with any casino, poker room or hotel. Every table value links to the page it was read from; a value no official source states is left blank, badged and listed on the Flagged for review page. Nothing is inferred, estimated or filled in. Room rates, schedules and structures change without notice — reconfirm before any non-refundable payment. Must be 21+. If gambling is a problem, call the Nevada HelpLine 1-800-522-4700.

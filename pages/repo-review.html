Findings from the review

  • The root site is generated by scripts/build_ea99006a.py from data/ea99006a/, validated by scripts/check_ea99006a.py and monitored by scripts/recheck_ea99006a.py. Earlier generators remain in scripts/ and are not deleted, but they no longer produce the root site.
  • Thirteen pull requests were merged before this session and one (PR #30) was open and idle. This session took over the root site instead of adding another dashboard folder, so there is one published answer per question rather than several conflicting ones.
  • Every session folder other than data/ea99006a/, work/ and the root site files is treated as read-only here.
  • A compiled Python file, tools/__pycache__/data.cpython-311.pyc, is committed in the tree. It was flagged by an earlier session and is left in place rather than deleted without that session's say.
  • Session folders disagree with each other on three numbers: the count of confirmed single-entry Venetian events (20 / 30 / 64 / 0), the Bellagio Saturday buy-in ($1,000 / $1,100 / $600) and the Wynn resort fee ($55 / unverified). This build resolves them from official sources and records the outcomes on the Flagged for review page.

  • The root site is now generated by scripts/build_bdcaf0bf.py from data/bdcaf0bf/, checked by scripts/check_bdcaf0bf.py and refreshed daily by .github/workflows/integrate-bdcaf0bf.yml. scripts/build_ea99006a.py and scripts/build_251c122f.py remain in the tree, and their data folders are still refreshed by their own workflows, but neither one writes the published site any more - that alternation was the repo's worst defect (flagged as B02).
  • Fourteen session folders (docs/, site/, site-*/, dashboard-*/, planner-*/, data-*/, tools/) each publish a variant of the same brief with their own numbers. They are preserved untouched; the root site is the canonical one. This is a decision for the owner, not for an agent session, and it is listed on the suggestions board.
  • Three different confirmed-single-entry counts have been published for the same 94 Venetian rows (0, 55 and now 53). This build states its rule explicitly on the single-entry page and prints the row-level disagreements instead of hiding them.
  • The room-rate column is blank on every hotel: no official page states a dated rate for the planned dates, and the poker-suite page's $119/$209 figures are published as a starting rate conditional on play. The site keeps those numbers as a labelled rate-floor basis rather than laundering them into a quote.
  • The Caesars corporate disclaimer states a resort-fee *range* ($45-$60) and some cached copies of the same page still show $45-$50, so the fee for those properties cannot be turned into a per-night number from an official source. Recorded as flag B03 with the live quote.
  • Nine Venetian structure sheets print a late-registration clock that does not follow from their own level lengths (for example sheet 6 prints 10 levels + break as 4:55 PM where the same sheet's 30-minute levels from an 11:10 AM start give 4:25 PM). The printed clock is used, the arithmetic is flagged, and nothing is 'fixed' silently.
  • Two rows that an earlier session confirmed as single-entry (events #18 and #58, the PokerAtlas Valuetown bounty) carry a sheet sentence selling subsequent buy-ins at a member price. They are now in the excluded section, and the disagreement is recorded row by row.
  • The sandbox that authors this repository cannot open a TCP connection to casino hosts, so live reading happens on GitHub Actions runners and through the agent's page-fetch tool; the hashes and quotes committed with each value are what makes that auditable.
  • One committed file is a compiled Python artefact, tools/__pycache__/data.cpython-311.pyc; it was flagged by an earlier session and is left in place rather than deleted without that session's say.

How the overlap check works. Official sheets publish a start time and a late-registration deadline, never an expected finish time, so a day is planned as: primary event first, and a fallback that can still be entered after the primary's registration window closes - i.e. a conditional re-entry if you are knocked out early. Where a row has no published deadline, the 4.0-hour planning assumption is used and the row says so. This is a planning aid, not a verified finish time (F42).

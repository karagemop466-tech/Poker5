Suggestions & improvement backlog

S-01 — Fetch official structure sheets and confirm single-entry vs re-entry

Owner: session-1 · Effort: medium · Status: proposed

Many multi-flight WPT/Venetian events allow one entry per starting flight but permit re-entry across flights. The structure sheets (wynnpoker.com; Venetian schedule PDF) were not fully fetched. Confirm which events are truly freezeout/single-entry so the main table doesn't mislead.

S-02 — Add live date picker + true-cost calculator

Owner: session-1 · Effort: high · Status: proposed

Add a date picker so the user can select their trip dates, then show only tournaments running on those dates and compute each hotel's true cost/night for the stay length (base + resort fee + tax + parking × nights).

S-03 — Verify every table row from official sources; blank + flag unverified

Owner: session-1 · Effort: high · Status: proposed

Continue line-by-line verification. Where a value can't be confirmed from an official source, leave it blank and mark "unverified" (already done for several rows). Prioritize: Venetian daily start times, Wynn daily status during WPT WC, MGM Grand data (official site 500s), all future room rates.

S-04 — Add driving/rideshare alternatives + parking cost detail

Owner: session-1 · Effort: low · Status: proposed

Some users won't walk 20–25 minutes. Add rideshare cost estimates and valet vs. self-parking costs per hotel so distance can be traded against cost.

S-05 — Tournament result tracking (finished events)

Owner: session-1 · Effort: medium · Status: proposed

After each event day, record results/placements so the user can see which flights actually ran and field sizes — helps decide whether to re-enter a later flight.

S-06 — Loyalty-status fee waivers (Caesars Rewards Diamond/Seven Stars; MGM Rewards Gold+)

Owner: session-1 · Effort: low · Status: proposed

Add a toggle: "I have elite status" to waive resort/parking fees where applicable and recalculate true cost per night.

S-07 — Mobile optimization + offline mode

Owner: session-1 · Effort: medium · Status: proposed

Most users will check tables on their phones in the casino. Tighten mobile table scrolling, add a "save for offline" toggle, and cache key data.

S-08 — Add more Strip poker rooms (Resorts World, Planet Hollywood, Park MGM, Mirage/Hard Rock)

Owner: session-1 · Effort: medium · Status: proposed

Coverage currently centers on Venetian, Wynn, Caesars/Horseshoe, ARIA, Bellagio, MGM. Add other Strip rooms with daily tournaments so the user can truly "play all day."

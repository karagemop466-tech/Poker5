Sources and automatic re-check

Each row of every table links to one of these URLs. A GitHub Actions job (.github/workflows/source-monitor-aecba91e.yml) re-fetches all of them every morning, compares the page against the stored snapshot, appends to data/aecba91e/change-log.json, marks the affected rows "source changed" and rebuilds the site. A fetch failure never marks a row; it records the status as unreachable instead.
